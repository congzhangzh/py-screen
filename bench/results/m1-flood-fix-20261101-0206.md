## Erratum (2026-11-01, added later)

The py-screen row "Key → echo, other window floods" (5000 ms) is **void**: the bench
started the flood with `pys new` before any window existed, so on py-screen the flood was
window 0 and the markers were typed into `yes`. screen's setup was right. Fixed in
`bench/m0_speed.py` (window 0 is now a shell). The starvation itself was real: the M0 code
(a95b4d3), run through `tests/test_flood.py` with the correct setup, gave no echo within the
3 s cap on any sample. The other rows stand, except that the idle-CPU row ran with 9
py-screen windows instead of 10 (the same bug).
